For an installation already running Ruphish, follow [Upgrade Ruphish](../administration/hosting-and-maintenance/upgrades.md). That procedure covers Docker and binary replacement, automatic database updates, verification, and restoring a matching release with its backup.

If the database still belongs to Gophish, use [Migrate the database](from-gophish.md) first. Replacing an executable without reviewing Gophish conversion and client changes is not the same operation.
