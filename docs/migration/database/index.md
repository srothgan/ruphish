| Engine | Procedure |
| --- | --- |
| SQLite | [Back up and convert a database file](sqlite.md). |
| MySQL | [Restore and convert a database on a supported MySQL server](mysql.md). |

Both procedures apply to UI and API users. PostgreSQL is available for Ruphish installations but is not a direct target for Gophish conversion.
