Learning pages are reusable explanations hosted by Ruphish. A campaign can redirect participants to one after an acknowledged submission. Opening a learning page does not create an interaction event or record training completion.

## Create and check a page

Open **Resources → Learning pages → Create**. Enter a name and write the explanation in the HTML or visual editor. You can also import HTML or resource JSON. Use **Preview** and **Check learning page** before saving. Administrators can also add available entries from the **Learning pages** tab in the [Starter Template Repository](starter-templates.md); each addition creates an independent resource copy.

Pages support static text, styling, permitted embedded images and ordinary links. Forms and input controls are removed from the public representation. Authored scripts, external resource loading and automatic redirects are blocked. Recipient template expressions are displayed literally; learning pages do not receive recipient context. Checks warn about removed controls and executable content, without requiring a submission form.

The saved authored HTML remains editable. Preview shows the restricted public representation. Review appearance, links and keyboard navigation in your browser before using the page.

## Select the campaign destination

During campaign creation or draft editing, choose **Learning page** under **Redirect destination**, then select the saved page. Review the selection before launching. Ruphish constructs the destination on the campaign's public origin; you do not need to enter its URL.

Choose **Custom redirect** to supply an HTTP(S) or relative URL. Leave that URL empty to stay on the landing page. Existing landing-page redirect defaults remain available for custom redirects.

A launched campaign's destination cannot be changed. Editing the selected learning page changes the content served to its consumers; content is not frozen at launch. Duplicate a learning page when another campaign needs independent content. Deletion is blocked while an unfinished campaign references it. A draft whose selected page has been deleted must select another page before launch.

## Public availability

Learning pages are available without an administrator login at `/learn/{public-page-id}` on an enabled, eligible public domain owned by the resource owner. The identifier is generated by Ruphish. Access does not require a recipient link or an active campaign. Unknown or deleted pages return a not-found response.

For automation, see the [learning pages API](../api/learning-pages.md). The same [participant-data restrictions](participant-data.md) apply throughout the submission and redirect workflow.
