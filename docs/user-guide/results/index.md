Start with the question you want to answer. The dashboard highlights operational work; campaign Results examines filtered observations; exports provide records for further work.

| Question | View |
| --- | --- |
| How are recent campaigns and delivery problems looking? | [Dashboard](dashboard.md) |
| What happened in this campaign or for this recipient? | [Campaign results](campaign-analysis.md) |
| How do I correct an individual event? | [Event corrections](correcting-events.md) |
| What exactly do these numbers mean? | [Metric definitions](metrics.md) |
| How can I work with these records elsewhere? | [CSV and Excel exports](exports.md) |

An observation records a request or system outcome. It does not establish human intent. Keep that distinction when presenting results to others.
