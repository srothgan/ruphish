## Start from the dashboard

The dashboard shows saved drafts, recent campaigns, and issues that need attention. Use it to resume work or open a campaign.

Recent-campaign click and report rates use that campaign's recorded sent-recipient count. They cover the campaign's recorded sends, rather than being limited by another dashboard period selection.

For a failed or unconfirmed email, use the campaign's **Sending** tab. For opens, clicks, submissions, and reports, use **Results**.

## Read activity in context

A recorded request is an observation, not proof of a person's intention. Mail scanners can follow links, email clients can block images, and repeated requests can come from one recipient.

When presenting findings, state the campaign and selected filters, distinguish people from repeated events, and explain the relevant measurement limits. [Understand the metrics](metrics.md) covers those distinctions.
