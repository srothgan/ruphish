Start with a small local exercise. You'll learn how the pieces fit together without sending messages to real recipients.

1. Read [What is Ruphish?](introduction.md) for the product's purpose and current scope.
2. Learn the [core concepts](concepts.md): recipients, resources, drafts, and campaigns.
3. Follow [installation](installation.md) to build the application, then use the [first-campaign tutorial](first-campaign.md) to try the complete workflow.

If someone already runs Ruphish for you, ask them for your administrator-interface address and account. You can skip building the application and go straight to the [user guide](../user-guide/index.md).

If you have an existing Gophish database, start with [migration](../migration/index.md). Starting against existing data is an upgrade operation, not a fresh installation.
