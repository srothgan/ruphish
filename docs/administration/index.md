Administration covers two responsibilities. You may handle both, or share them with someone else.

| Responsibility | Start here |
| --- | --- |
| Manage the people using Ruphish | [Team administration](team-administration/index.md): shared access, accounts, company settings, optional features, and closing active campaigns. |
| Keep Ruphish running | [Hosting and maintenance](hosting-and-maintenance/index.md): Docker or binary services, network access, databases, configuration, backups, and monitoring. |

Team administrators work in the browser with an **Administrator** account. Hosting tasks require access to the computer, containers, or database running Ruphish; an application account alone does not provide that access.

If you want to install Ruphish and try it on your own computer, begin with [Getting started](../getting-started/index.md). For creating resources, running campaigns, and reading results, use the [User guide](../user-guide/index.md).
