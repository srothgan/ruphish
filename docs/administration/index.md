Installation operators manage processes, networks, storage, and configuration. Account administrators manage application access. One person may do both, but the permissions and procedures are different.

| Task | Guide |
| --- | --- |
| Build a fresh local instance | [Installation](../getting-started/installation.md) |
| Set exact options | [Configuration](configuration.md), [CLI](cli.md) |
| Connect public domains and integrations | [Listeners/TLS](listeners-and-tls.md), [outbound connections](outbound-connections.md) |
| Choose storage | [Databases](databases/index.md) |
| Control optional features and close active campaigns | [Company settings](settings.md) |
| Manage application access | [Accounts and permissions](accounts-and-permissions.md) |
| Send events to another service | [Webhooks](webhooks.md) |
| Keep the instance running | [Process operation](running-the-service.md), [logging](logging.md) |
| Protect or restore data | [Backup and recovery](backup-and-recovery.md) |
| Diagnose a failure | [Troubleshooting](troubleshooting.md) |

For an existing Gophish database or an application upgrade, start with [migration](../migration/index.md). The local tutorial fixture is an exercise environment, not a published deployment package.
